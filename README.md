# Структуры и алгоритмы компьютерной обработки данных

Лабораторные работы по дисциплине «Структуры и алгоритмы компьютерной обработки данных».

- **Автор:** Мельников А.А., группа ИТз-441 (заочная форма обучения)
- **Преподаватель:** ст. преп. Зубков А.В.
- **Язык и технологии:** C#, Windows Forms, .NET 8

## Программы

Готовые программы лежат в корне репозитория. Скачайте exe и запустите.

| Программа | Что делает |
|-----------|------------|
| [Lab1_Parallelepiped.exe](Lab1_Parallelepiped.exe) | **ЛР 1. Среда разработки Visual Studio.** По сторонам a, b, c прямоугольного параллелепипеда вычисляет площадь поверхности S = 2(ab + bc + ac) и объем V = abc, рисует параллелепипед. |
| [Lab2_SequentialSearch.exe](Lab2_SequentialSearch.exe) | **ЛР 2. Последовательный поиск.** Сравнивает по времени поиск в неупорядоченном массиве (обычный и с барьером) и в упорядоченном массиве на массивах до 50 млн элементов. |
| [Lab3_BinarySearch.exe](Lab3_BinarySearch.exe) | **ЛР 3. Бинарный поиск.** Сравнивает неоптимальный, оптимальный, интерполяционный и «последовательный» бинарный поиск с последовательным поиском в упорядоченном массиве до 100 млн элементов. |
| [Lab4_Hashing.exe](Lab4_Hashing.exe) | **ЛР 4. Поиск методом хеширования.** Сравнивает хеш-функции (деление, середина квадрата, свертывание, умножение) по числу коллизий, а также метод открытой адресации и метод цепочек по времени и числу сравнений. |

Для запуска нужны Windows x64 и [.NET Desktop Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0) или новее.

| Папка | Работа |

Открыть и собрать: файл `SAOD.sln` в Visual Studio 2022 или командой `dotnet build SAOD.sln`.
